# Screenshot Instructions

Your rubric asks for a screenshot showing the application running.

Use the included sample screenshot only as a placeholder. For the actual submission, run the game on your Mac and take your own screenshot.

## macOS screenshot steps

1. Build and run the C++ SFML version:

```bash
cd cpp-sfml
cmake -S . -B build
cmake --build build
./build/SpaceInvaders
```

2. Press Shift + Command + 4.
3. Drag over the game window.
4. Save the screenshot.
5. Submit that screenshot with `main.cpp` and `Final_Project_Documentation.docx`.
